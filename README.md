# Lanchonete do Bairro

Projeto prático de Git, GitHub e GitFlow desenvolvido para a disciplina de Engenharia da Qualidade e Confiabilidade da UniRV.

## Estrutura do Projeto
- `index.html`: Página principal com a estrutura visual do cardápio.
- `promocoes.html`: Página especial de promoções da lanchonete.
- `style.css`: Estilização e identidade visual responsiva do site.
- `cardapio.js`: Lógica de renderização dinâmica do cardápio e interações de pedidos.

## Como Executar
Abra o arquivo `index.html` em qualquer navegador moderno para visualizar e testar o projeto de forma interativa.
